# 导入带引号的 CSV 日志时，字段被逗号切碎了

## 现象

我们的访问日志里有一列是用户代理串（User-Agent），里面本身就带逗号，导出成 CSV 时是用双引号包起来的，像这样：

```
2026-08-30,"Mozilla/5.0 (X11; Linux x86_64)",200
```

用 `textkit.csvline.parse_line()` 读这一行，本来应该切出 3 个字段，实际切出了 4 个：日期、`"Mozilla/5.0 (X11; Linux x86_64)"` 被从中间的逗号处劈成了两半。

## 复现步骤

```python
from textkit.csvline import parse_line

print(parse_line('"a,b",c'))
```

期望输出 `['a,b', 'c']`，实际输出 `['"a', 'b"', 'c']`。

## 影响

导入脚本按字段个数校验每一行，多出来的字段会让整批日志被判成格式错误，当天的数据就全丢了。这个月已经出现两次。

## 期望行为

双引号包起来的字段里，逗号是普通字符，不是分隔符。另外按 CSV 的通行写法（RFC 4180），引号内要表示一个双引号本身时写成两个连续的双引号，解析时应当还原成一个。

外层的那对引号本身不属于字段内容，不要出现在结果里。
