## 四、这台机器的几个坑（AGENTS.md 里没有的）

- `bench-postgres` 容器经常停着，任何入库步骤前先 `make db-up`。
- 终审表 CSV 的 `review` 列可能超过 csv 模块默认上限，读它要 `csv.field_size_limit(sys.maxsize)`（promote.py 已改，别处自己读要注意）。
- 官方题没有候选行，`import-review` 的理由记不进库，只在 CSV 里 —— CSV 必须进仓库。
- 补新题的验证用 `cli.validate run --task … --scope declared`，**不要** `make swebench-validate`（会把已终审的题重验回 REVIEW_REQUIRED）。
- matplotlib 的 git 镜像 WSL 里拉不动，走 Windows `git.exe -c http.proxy=http://127.0.0.1:10808` 拉进 `D:\Documents\swebench-git\`，再从 `/mnt/d` fetch。
- 门禁实验在未提交的工作区上跑会标 `dirty=true`，发布也要 `ALLOW_DIRTY=1`；前几版都是这么来的，指纹里如实记着。
