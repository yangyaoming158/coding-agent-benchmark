## 四、这两天踩的坑（AGENTS.md 里没有的）

- `make check` 在 Postgres 停着时 290 条集成测试**静默 skip、退出码仍 0**——看 passed 数时核 skipped 是不是 2。
- `pkill -f 'python3 -m app.worker'` 会把自己的 shell 一起杀掉（命令行含同一模式）。取 pid：
  `ps -eo pid,args | grep '[p]ython3 -m app.worker' | awk '{print $1}'`，再 `kill -TERM`。
- 起 Worker 后立刻 `ps` 会看到 3–4 个临时 python 进程，几秒后只剩一个；监控按进程名判断，别记 pid。
- `cli.attribute rules --run-id` 的 id 是**单次执行** id 不是实验号；不给参数就全库扫、已判过的跳过。
- `retry-failed` 只补没有 canonical 结论的题（C-25），已有结论的平台故障不会重判。
- 同一个 Agent 有两份启用配置时 `--agent` 不唯一，实验命令要带 `--config aider@deepseek-flash`（Makefile 用 `CONFIG=`）。
- 平台按美元牌价报的成本比 DeepSeek 人民币账单高约 1.3 倍；aider 在大仓库上几乎不命中缓存、每题约 ¥0.4，是最贵的。
- DeepSeek 折扣时段的定义查不到，中午和半夜每题花费差别不大，别拿"低峰"当省钱依据。
